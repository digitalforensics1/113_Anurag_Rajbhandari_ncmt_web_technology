// // Flexbox: A CSS3 layout model that arranges elements in a flexible row or column. Function: Provides easy alignment, spacing, and distribution of items inside a container. Usages: Best for one‑dimensional layouts (either row OR column). Note: Use display:flex on the parent container. extra key point: Flexbox simplifies vertical and horizontal centering, and adapts well to different screen sizes. Code eg: .container { display: flex; justify-content: center; /* horizontal alignment */ align-items: center; /* vertical alignment */ } note: 1. justify-content → controls horizontal alignment (start, center, space-between). 2. align-items → controls vertical alignment (start, center, stretch). 3. flex-direction → sets row or column layout. 4. flex-wrap → allows items to wrap onto multiple lines.
